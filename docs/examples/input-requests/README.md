# Input request templates

These JSON documents illustrate input request contract v1. Copy a template next
to the inputs it declares, replace the example paths and versions, and calculate
every placeholder SHA-256 digest before validation. They are templates, not
bundled analysis fixtures, and are not expected to run from this documentation
directory.

See [`input-request-v1.md`](../../contracts/input-request-v1.md) for the
normative schema and the distinction between `inspect` and `validate`.
